# Code of Conduct

DUSK follows the [OWASP Code of Conduct](https://policy.owasp.org/operational/code-of-conduct.html).
Everyone participating in this project must provide a welcoming, safe, and
professional environment, regardless of background or identity.

## Reporting

Report conduct concerns privately to the project maintainers listed in
[GOVERNANCE.md](GOVERNANCE.md). If a concern involves a maintainer, or cannot be
resolved within the project, use the reporting and escalation routes in the
OWASP Code of Conduct.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not this
conduct process.
